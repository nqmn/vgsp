Data provenance & mathematical interpretation

Real embedded validation data: 2,150 stratified deterministic InSDN Fold 1 validation rows (773 Normal / 1,377 DDoS). Source SHA-256: d2bbdca5eccb09874ad0b901b2c5841f0b46df30fb8740fbe8852b0b299ac80a.

Protocol: stratified 80:20 development / hold-out (random state 42); 5-fold StratifiedKFold on development only (shuffle, random state 42); the displayed Fold 1 validation set is not the independent 20% hold-out. Median imputation, MinMaxScaler, CVR ranking and projection weights are fitted using Fold 1 training rows only. No preprocessing, CVR or weights are refitted in this HTML; descriptive class density is estimated from the embedded validation z values.

VGSP: Wⱼ = p₀v₀ⱼ + p₁v₁ⱼ, Bⱼ = p₀p₁(μ₀ⱼ − μ₁ⱼ)², CVRⱼ = Bⱼ/(Bⱼ + Wⱼ + 10⁻¹⁰), wⱼ = CVRⱼ/(Σᵢ CVRᵢ + 10⁻¹⁰), zᵢ = Σⱼ wⱼxᵢⱼ (seven MinMax-scaled selected inputs). Original 77 features are visualized as a feature inventory. The rotating 3D view displays only Protocol, Down/Up Ratio and Init Bwd Win Byts; it is not a 7D geometrical projection. Movement toward the 1D axis is display interpolation; the final horizontal coordinate uses the actual weighted 7D scalar. Vertical jitter applies only to drawing.

Decision Tree (V3): A frozen DecisionTreeClassifier(random_state=42) is fitted on 121,833 training examples from the same Fold 1, using VGSP-generated z only. Its actual scikit-learn thresholds, node children, leaf distributions, and full validation evaluation (30,459 observations) are embedded. The browser performs inference by traversing that tree; no training occurs in the browser. The full Fold 1 confusion matrix is [[10948,0],[2,19509]], with 99.9934% accuracy. A 7-input DT baseline on the same training/validation split had 25 nodes versus 27 for the VGSP 1D DT, so model-size reduction is not claimed. The separate 2,150 point illustrative sample happens to have no misclassifications and is not used as the accuracy benchmark.

Interpretation: Inference from 1D simplifies the per-node decision variable (z ≤ learned threshold), but calculating z requires seven weighted feature values and original flow feature extraction. End-to-end latency or controller deployment efficiency cannot be inferred from input dimensionality alone.

Density: Gaussian KDE calculated from the embedded validation z values, with per-class peak normalization. It is for visual comparison and does not represent probabilities or classifier predictions. Real labels are shown; no classifier is fitted. This HTML contains no external libraries, assets or network requests.
